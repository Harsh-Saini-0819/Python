# 🎯 Number Guessing Game

A simple, interactive command-line **Number Guessing Game** built with Python. The program generates a random number between 1 and 100, and the player tries to guess it with dynamic feedback (higher/lower) provided after each attempt.

---

## 🚀 Features

*   **Randomized Targets**: Every game uses a uniquely generated number from `1` to `100`.
*   **Live Feedback**: Tells you instantly if your guess is too high or too low.
*   **Infinite Loop Gameplay**: Runs continuously until you find the exact matching number.

---

## 🛠️ How to Run

### Prerequisites
Make sure you have Python 3 installed on your machine.

### Execution Steps
1. **Clone the repository** (or copy the script file):
   ```bash
   git clone https://github.com
   cd YOUR-REPO-NAME
   ```
2. **Run the script** directly from your terminal:
   ```bash
   python main.py
   ```
